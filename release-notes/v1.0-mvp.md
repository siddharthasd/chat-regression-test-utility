# EvalBrew v1.0-mvp — Release Notes

**Released:** 2025 (initial MVP)

## Overview

First production release of EvalBrew — a platform for orchestrating structured LLM evaluations via pluggable connectors and evaluators. This release delivers the complete core platform: data model, job lifecycle, connector/evaluator registries, and a full web UI.

---

## Core Platform

**Data Model & Persistence (009)**
SQLAlchemy-based persistence layer covering jobs, runs, results, connectors, and evaluators. Includes Alembic migrations for schema versioning.

**Standard Evaluation Contract (006)**
Defined the canonical HTTP contract between the harness, connectors, and evaluators — including request/response schemas, credential masking, and error codes.

**Tester Identity (010)**
`createdBy` stamping on jobs at creation time; exposed in the dashboard, export, and job detail views.

**Connector Framework (007)**
Plugin-style remote connector support. Connectors expose a standard HTTP interface; the harness calls them per-utterance during job execution.

**Evaluation Agent Framework (008)**
Pluggable remote evaluator support with the same pattern. Shared auth harness (`harness.remote.auth`) de-duplicates credential handling across both connector and evaluator calls.

**Job Execution Engine (012)**
Async orchestrator (Module 10) that fans out utterances to connectors, streams results to evaluators, persists scores, and manages job lifecycle state.

**CSV Upload & Validation (011)**
File upload endpoint with header validation, column mapping (`utteranceText`), and row-level error reporting before a job is submitted.

---

## Registries & Management

**Connector Registry (013)**
CRUD UI and API for registering, editing, and deleting connectors. Includes a **Test Connection** button to validate reachability before use.

**Evaluator Registry (014)**
Same pattern for evaluators, with per-evaluator configuration and connection testing.

**Azure AD RBAC (015)**
Microsoft Entra ID (Azure AD) integration for SSO. Role-based access control gates admin-only actions. Includes CLI tooling and an admin user guide.

**Admin Tools (016)**
Admin dropdown menu and Job Maintenance page. Role-scoped **Clear All Jobs** action respects the caller's permission level.

---

## Web UI

**Dashboard & Job Listing (002)**
Main landing page with paginated job table, status badges, `Created By` filter, and job-level actions (view, cancel, clear).

**Job Creation Wizard (003)**
Step-by-step wizard for configuring a new job: connector selection, evaluator selection, CSV upload, and review before submission.

**Job Detail & Traceability View (004)**
Per-job drill-down showing run metadata, per-utterance results, scores, and reasoning traces.

**Results Export (005)**
Export job results to CSV. Includes full job metadata block (connector, evaluator, `createdBy`, timestamps) and per-utterance score rows.

**Bootstrap 5 UI**
Full UI redesign using Bootstrap 5 — professional dashboard layout, responsive navigation, and consistent component styling.
