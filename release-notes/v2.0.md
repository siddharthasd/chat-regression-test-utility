# EvalBrew v2.0 — Release Notes

**Released:** 2025

## Overview

v2.0 introduces live chat evaluation — real-time, turn-by-turn LLM assessment streamed directly in the browser via SSE. This release also rebrands the product as **EvalBrew** and adds an in-app documentation module.

---

## New Features

**Live Chat & Real-Time Evaluation (Feature 017)**
A new chat interface lets testers interact with a connected LLM in real time while the configured evaluator scores each turn as it completes. Key capabilities:

- **SSE streaming** — evaluator scores and reasoning arrive incrementally; no polling.
- **Dual view modes** — side-by-side Developer View (full reasoning trace) and User View (scores only), switchable mid-session.
- **Turn separators** — "Turn N" labels appear in the eval pane as each exchange completes.
- **Autoscroll** — chat and eval panes scroll automatically as new content arrives.
- **Score display** — numeric score shown alongside reasoning in the eval pane and User View.
- **Test ID** — each live session receives a unique Test ID visible in the UI.
- 536 tests shipped with this feature.

**EvalBrew Rebrand**
Product renamed from its working name to **EvalBrew** across all UI surfaces, page titles, and documentation.

**Documentation Module**
New in-app Docs section with:
- **About** page — product overview and purpose.
- **Architecture** page — component diagram and data-flow description.

---

## Bug Fixes & Polish

- Fixed SSE connection lifecycle bugs that caused dropped messages on reconnect.
- Fixed browser scroll behaviour in the chat pane (page-level scroll no longer hijacked).
- Compact header reduces vertical space consumption on smaller screens.
- Info icon added next to the formatting notice in the eval pane.
- Dashboard query corrected for live-session job records.
- Event bus fix preventing duplicate score events from being emitted per turn.
- Wizard cleanup: stale state cleared when navigating back through steps.
