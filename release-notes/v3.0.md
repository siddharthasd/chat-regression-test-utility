# EvalBrew v3.0 — Release Notes

**Released:** 2026-07-10

## Overview

v3.0 adds analytics across both batch job runs and live chat sessions, introduces Accenture brand alignment across the UI, and cleans up dependencies.

---

## New Features

**Job Run Analytics Dashboard (Feature 018)**
A dedicated analytics view for completed job runs. Provides pass/fail breakdowns, score distributions, and per-evaluator metrics — giving teams a single place to track evaluation health over time.

**Utterance Intent Analytics (Feature 018-ext)**
Extended job analytics with intent-level breakdowns. A new `utterance_intent` field on results enables filtering and grouping by conversation intent, surfacing which intent categories score highest or lowest.

**Live Chat Analytics (Feature 019)**
Real-time analytics panel alongside the live chat interface. Streams running score averages, turn-level pass/fail indicators, and intent coverage as the conversation progresses — no page reload required.

---

## UI / UX

**Accenture Brand Alignment**
Switched to Arial typeface, black navbar, neutral backgrounds, and toned-down danger button styles to meet Accenture brand standards.

**Visual Redesign**
Prior purple/lavender theme replaced with the current neutral, professional palette featuring elevated cards and cleaner spacing.

---

## Maintenance

- Removed `gunicorn` and `werkzeug` from direct dependencies; `jinja2` declared explicitly to tighten the dependency graph.
- Corrected SSE protocol documentation in the evaluator developer guide (section 11).
